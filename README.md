# Chapter 2 – Understanding C# and .NET Core Console Applications

This repository contains the source code and exercises for **Chapter 2** of **C# 8.0 and .NET Core 3.0**.

The projects in this repository introduce the fundamentals of C# programming through a series of small, focused .NET Core console applications. Each project explores a key concept and is designed to help you build a solid foundation before moving on to more advanced topics.

## Topics Covered

The console applications in this repository cover:

- Understanding C# grammar and vocabulary
- Working with variables and data types
- Value types and reference types
- Working with `null` values
- Exploring .NET Core console applications
- Writing and running your first C# programs
- Practice exercises to reinforce the concepts learned

## Prerequisites

Before running these projects, ensure you have:

- Visual Studio 2019 or later
- .NET Core 3.0 SDK (or later)

## Getting Started

1. Clone this repository.

   ```bash
   git clone https://github.com/<your-username>/Chapter2.git
   ```

2. Open the `Chapter2.sln` solution in Visual Studio.

3. Select the project you want to run.

4. Right-click the project and select **Set as Startup Project**.

5. Press **F5** to run with debugging or **Ctrl+F5** to run without debugging.
